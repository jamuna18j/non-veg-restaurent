# 👑 THE ROYAL FEAST — Luxury Non-Vegetarian Restaurant

> *"A ROYAL FEAST FOR EVERY CRAVING."*

**The Royal Feast** is a breathtaking, luxurious, full-stack non-vegetarian restaurant website with a five-star dining ambiance, deep royal maroon (`#3B0718`) and antique gold (`#D4AF37`) palette, cinematic opening animation, continuous flowing silk background, and complete end-to-end ordering, tracking, and management capabilities.

## 🚀 How to Run the Project

### Prerequisites
- Node.js (v18+)
- npm

### Quick Start (Single Command)
From the root project directory:
```bash
npm start
```
Open **[http://localhost:5000](http://localhost:5000)** in your browser to experience the full application!

### Separate Development Mode (Optional)
If you wish to run the client Vite dev server with Hot Module Replacement:
```bash
# Terminal 1: Run Express Server
npm run server

# Terminal 2: Run Vite Dev Client
npm run client
```
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:5000`
